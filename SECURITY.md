# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in UNIZIK Builders Hub, please report it responsibly:

**DO NOT** open a public GitHub issue for security vulnerabilities.

Instead, report security issues privately:
- Email: **donaldanyamba@gmail.com**
- Subject line: `[SECURITY] Brief description of the issue`

### What to include

1. Description of the vulnerability
2. Steps to reproduce the issue
3. Potential impact (what data or systems are affected)
4. Any suggested fixes (if you have them)

### What to expect

- I'll acknowledge your report within 48 hours
- I'll work on a fix and keep you updated on progress
- Once the fix is deployed, I'll credit you in the commit (unless you prefer to remain anonymous)

## Scope

This platform handles real member data:
- Email addresses
- Phone numbers
- Student matric numbers
- Profile photos

Security matters here. If you find something that puts member data at risk - authentication bypasses, data leaks, injection vulnerabilities, insecure API endpoints - please report it.

## Out of scope

- Social engineering attacks against community members
- Attacks requiring physical access to AWS infrastructure
- Denial of service (DoS) attacks

---

Thank you for helping keep UNIZIK Builders Hub and our members safe.
