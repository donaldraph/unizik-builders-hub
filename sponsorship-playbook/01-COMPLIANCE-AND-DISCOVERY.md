## Compliance Rules Extracted — Must-Follow for All Proposals

### 1. Group Naming Convention
- **Required format:** "AWS Student Builder Group at Nnamdi Azikiwe University"
- **SCD naming:** "AWS Student Builder Groups Student Community Day Awka"
- Do NOT change this format. Do NOT abbreviate AWS.

### 2. Logo & Brand Usage
- All AWS Student Builder Group logos and fonts are provided in Box (directory `01-`)
- **Primary font:** Amazon Ember
- Do NOT recolor or stretch logos
- Sponsor logos may appear alongside AWS branding but must not alter or overshadow the AWS Student Builder Group brand identity
- Competing cloud provider logos (Google Cloud, Microsoft Azure, GCP) must NEVER appear on AWS-branded event materials

### 3. Sponsorship Rules
- **Permitted sponsor types:** Financial (cash) and In-Kind (goods/services)
- **Prohibited sponsors:** Google, Microsoft, or any competing cloud provider
- If co-hosting with GDG or Azure groups, split costs equally — but competing cloud branding stays off AWS materials
- All sponsors must agree to the event Code of Conduct
- Sponsors must have a positive reputation aligned with group values
- Sponsor benefits must be clearly tiered with documented deliverables
- Post-event thank-you with attendance, feedback, and photos is mandatory

### 4. Event Requirements
- **Frequency:** 6 events minimum in 12-month leadership tenure
- **Duration:** Minimum 1.5 hours per event
- **Content:** Must include AWS-related content to qualify for badges
- **Attendance:** Target 12+ attendees minimum; explain and plan to increase if under
- **Inclusion:** Events must be welcoming to all. Enforce Code of Conduct
- **Feedback:** CSAT survey at end of every event (SCD: s12d.com/aws-scd26)
- **Meetup.com:** Every event MUST be published on Meetup.com (no substitutes)
- **AWS Builder Center:** Distribute unique Builder Center sign-up link via QR code at every event
- **Social Media:** Use #AWSStudentBuilderGroup hashtag on all posts

### 5. SCD-Specific Rules (from SCD Playbook)
- Planning starts 3 months before event
- Planning Committee responsible for: agenda, marketing, financials, venue, food/beverage
- Speakers are community-sourced (CFP via Papercall.io or Sessionize)
- Speakers need 30-minute online orientation before event
- All speakers and attendees must agree to AWS Code of Conduct
- Venue should be free or low-cost (on-campus preferred)
- Must have backup plans for internet and power
- Receipts due within 14 days to StudentBuilders@amazon.com
- Budget recommendation: $5/attendee for food + swag combined
- Use Streamyard or Twitch for any online streaming component

### 6. Financial Accountability
- All expenses must be receipted
- Budget should include 10% buffer for last-minute adjustments
- Categorize expenses under: Agenda & speaker selection, Marketing, Financials
- Expense report template available in Box folder
- Submit completed expense Excel to StudentBuilders@amazon.com within 14 days

### 7. Post-Event Reporting (to AWS)
- Thank sponsors, speakers, and helpers
- Debrief with organizers
- Settle finances and submit documentation
- Clean up attendee list for badging
- Claim Platinum level badge and upload attendee list
- Measure impact: membership growth, social media growth
- Send follow-up communications about upcoming events
- Consider issuing certificates of recognition for top volunteers
