## Compliance Foundation

All documents adhere to:
- AWS Student Builder Group naming conventions
- AWS co-branding and logo usage rules (Amazon Ember font, no recoloring/stretching)
- Competing cloud provider exclusion (no Google/Microsoft/Azure)
- Meetup.com event publishing requirement
- AWS Builder Center sign-up link distribution
- CSAT survey requirements
- Code of Conduct enforcement
- Financial accountability (receipts within 14 days to StudentBuilders@amazon.com)

## Quick-Start Outreach Order

1. Read `01-COMPLIANCE-AND-DISCOVERY.md` to internalize the rules
2. Use `CONTACT-RESEARCH.md` to get verified contact details for each prospect
3. Use `02-SPONSOR-DIRECTORY.md` to build your prospect list (prioritize Diamond and Gold targets)
4. Copy-paste pitches from `03-PITCH-ENGINE.md`, customize the bracketed fields
5. Attach the SCD deck (`UNIZIK-AWS-SBG-Partnership-Deck.html` → print to PDF) to your outreach
6. Reference `04-SPONSORSHIP-TIERS.md` when negotiating tier selection and scope
7. Use `05-EVENT-FORMATS.md` for event planning once sponsors confirm
8. Launch `06-CURRICULUM-ENGINE.md` as your year-round engagement program
9. Deploy `07-POST-EVENT-ROI-KIT.md` within 72 hours of each event
