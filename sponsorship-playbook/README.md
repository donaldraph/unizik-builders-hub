## Compliance Foundation

All documents adhere to:
- AWS Student Builder Group naming conventions
- AWS co-branding and logo usage rules (Amazon Ember font, no recoloring/stretching)
- Competing cloud provider exclusion (no Google/Microsoft/Azure)
- Meetup.com event publishing requirement
- AWS Builder Center sign-up link distribution
- CSAT survey requirements
- Code of Conduct enforcement
- Financial accountability (receipts within 14 days to StudentBuilders@amazon.com)

## Quick-Start Outreach Order

1. Read `01-COMPLIANCE-AND-DISCOVERY.md` to internalize the rules
2. Use `02-SPONSOR-DIRECTORY.md` to build your prospect list (prioritize Headline and Gold targets)
3. Copy-paste pitches from `03-PITCH-ENGINE.md`, customize the bracketed fields
4. Attach tier benefits from `04-SPONSORSHIP-TIERS.md` as a PDF to your outreach
5. Use `05-EVENT-FORMATS.md` for event planning once sponsors confirm
6. Launch `06-CURRICULUM-ENGINE.md` as your year-round engagement program
7. Deploy `07-POST-EVENT-ROI-KIT.md` within 72 hours of each event
