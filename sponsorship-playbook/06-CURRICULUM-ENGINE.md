## 4-Stage Technical Progression

```
 STAGE 1          STAGE 2          STAGE 3          STAGE 4
 Cloud Explorer   Cloud Builder    Cloud Specialist  Cloud Champion
 Months 1-3       Months 4-6       Months 7-9        Months 10-12
 ─────────────>  ─────────────>   ─────────────>    ─────────────>
 Zero → CCP      CCP → Builder    Builder → SA/AI   Champion → Lead
 Ready            Portfolio        Cert Ready        Community Impact
```

### Stage 1: Cloud Explorer (Months 1-3)

| Attribute | Detail |
|-----------|--------|
| **Target** | Absolute beginners. Zero cloud knowledge assumed. |
| **Entry Requirement** | UNIZIK student, AWS Builder Center account, Meetup RSVP |
| **Exit Criteria** | Score 70%+ on Cloud Practitioner practice exam |
| **Goal** | AWS Cloud Practitioner certification readiness |

**Month 1 - Cloud Foundations & IAM**
- What is Cloud Computing? (on-prem vs cloud, CapEx vs OpEx)
- AWS Global Infrastructure (Regions, AZs, Edge Locations)
- IAM deep-dive (Users, Groups, Roles, Policies, MFA)
- AWS Management Console navigation + CLI basics

**Month 2 - Core Services**
- Compute: EC2 instance types, launch, connect via SSH
- Storage: S3 buckets, versioning, lifecycle policies
- Networking: VPC, subnets, security groups, NACLs
- Database: RDS fundamentals, DynamoDB overview

**Month 3 - Cloud Practitioner Exam Prep**
- Billing & pricing models (Free Tier, Reserved, Spot, Savings Plans)
- Shared Responsibility Model, AWS Well-Architected intro
- Full-length practice exams (2x timed mock tests)
- Exam strategy workshop: question patterns, elimination techniques

---

### Stage 2: Cloud Builder (Months 4-6)

| Attribute | Detail |
|-----------|--------|
| **Target** | Students who completed Stage 1 or hold Cloud Practitioner |
| **Entry Requirement** | 70%+ on CCP practice exam OR CCP certification |
| **Exit Criteria** | Deployed portfolio project on AWS, presented at Demo Day |
| **Goal** | Hands-on building confidence, portfolio-ready projects |

**Month 4 - Serverless Fundamentals**
- AWS Lambda: functions, triggers, environment variables
- API Gateway: REST APIs, stages, throttling
- DynamoDB: table design, partition keys, queries
- Mini-project: Serverless REST API (Lambda + API GW + DynamoDB)

**Month 5 - Containers & Deployment**
- Docker fundamentals, Dockerfile, images, containers
- Amazon ECS: task definitions, services, Fargate
- CI/CD basics: CodeCommit/GitHub → CodeBuild → CodeDeploy
- Mini-project: Containerized web app with CI/CD pipeline

**Month 6 - Full-Stack Project & Demo Day**
- Combine serverless + containers: architecture design
- Frontend hosting on S3 + CloudFront
- Project sprint: 3-week build cycle (plan → build → ship)
- Stage 2 Demo Day: present to community + judges

---

### Stage 3: Cloud Specialist (Months 7-9)

| Attribute | Detail |
|-----------|--------|
| **Target** | Confident builders choosing a specialization |
| **Entry Requirement** | Completed Stage 2 portfolio project |
| **Exit Criteria** | Score 75%+ on SAA or AI Practitioner practice exam |
| **Goal** | Solutions Architect Associate OR AI/ML Practitioner readiness |

**Month 7 - Architecture Patterns**
- AWS Well-Architected Framework (all 6 pillars)
- Multi-tier architectures, microservices patterns
- High availability: Multi-AZ, Auto Scaling, ELB
- Cost optimization patterns, right-sizing

**Month 8 - Specialization Track Split**

| Week | Solutions Architect Path | AI/ML Practitioner Path |
|------|------------------------|------------------------|
| 1 | Advanced VPC (peering, Transit GW, endpoints) | Amazon SageMaker Studio intro |
| 2 | Hybrid architectures (Direct Connect, VPN) | Bedrock & Foundation Models |
| 3 | Data lakes (S3, Glue, Athena) | ML pipeline: data prep → train → deploy |
| 4 | Migration strategies (6 Rs, AWS MGN) | Responsible AI, bias detection |

**Month 9 - Certification Prep Sprint**
- Week 1-2: Domain-by-domain review with practice questions
- Week 3: Full-length timed practice exams (2x)
- Week 4: Weak-area targeted review + exam strategy
- Certification voucher ceremony for qualifying members (70%+ on practice)

---

### Stage 4: Cloud Champion (Months 10-12)

| Attribute | Detail |
|-----------|--------|
| **Target** | Advanced builders, cert holders, emerging community leaders |
| **Entry Requirement** | Completed Stage 3 or holds Associate-level cert |

**Month 12 - Demo Day, Portfolio & Next Steps**
- Capstone presentations at Student Community Day or special event
- Portfolio finalization: GitHub, AWS Builder Center profile, LinkedIn

### Detailed Monthly Milestone Breakdown

#### Month 1: Cloud Architecture Jam - "Build Your First Cloud"
- **Format**: Teams of 3-4, 45-minute whiteboard challenge
- **Challenge**: Design a basic web hosting solution using only services learned this month (S3, IAM, basic compute)
- **Judging**: Clarity of diagram (30%), correct service selection (40%), cost awareness (30%)
- **Prize**: Winning team gets "First Architects" badge + bonus leaderboard points

#### Month 2: Cloud Architecture Jam - "The Resilient Startup"
- **Format**: Teams of 3-4, 60-minute challenge
- **Challenge**: A startup's website keeps going down. Design a fault-tolerant 2-tier architecture using EC2, VPC, S3, RDS
- **Judging**: High availability (40%), security (30%), cost efficiency (30%)
- **Prize**: Winning team featured on social media

#### Month 3: Cloud Architecture Jam - "Cost Detective"
- **Format**: Individual, 30-minute speed challenge
- **Challenge**: Given a mock AWS bill with waste (oversized instances, unused EIPs, unattached EBS), identify savings
- **Judging**: Total savings found (50%), correct reasoning (50%)
- **Prize**: "Cost Hawk" badge + AWS swag

#### Month 4: Cloud Architecture Jam - "Serverless or Bust"
- **Format**: Teams of 2-3, 60-minute challenge
- **Challenge**: Design a serverless campus event registration system (Lambda, API GW, DynamoDB, SES)
- **Judging**: Architecture correctness (40%), scalability (30%), cost (30%)
- **Prize**: Winning team presents at next community meetup

#### Month 5: Cloud Architecture Jam - "Ship It in a Container"
- **Format**: Teams of 2-3, 75-minute challenge
- **Challenge**: Containerize a provided app, design ECS deployment with CI/CD
- **Judging**: Working deployment (50%), pipeline design (30%), documentation (20%)
- **Prize**: "DevOps Rising Star" badge

#### Month 6: Cloud Architecture Jam - "Full Stack Blitz"
- **Format**: Individual or pairs, 90-minute capstone-style challenge
- **Challenge**: Design and present a full-stack architecture using all Stage 2 services
- **Judging**: Completeness (30%), cost optimization (20%), security (20%), presentation (30%)
- **Prize**: Featured project on group website + swag pack

#### Month 7: Cloud Architecture Jam - "Architect for Scale"
- **Format**: Teams of 3, 90-minute challenge
- **Challenge**: Scale a basic architecture from 100 to 100K concurrent users using Auto Scaling, ELB, caching, CDN
- **Judging**: Scalability proof (40%), Well-Architected alignment (30%), cost at scale (30%)
- **Prize**: "Scale Master" badge

#### Month 8: Cloud Architecture Jam - "Multi-Region Madness"
- **Format**: Teams of 3, 90-minute challenge (SA and AI tracks compete separately)
- **Challenge (SA)**: Design a globally distributed app with Route 53, CloudFront, multi-region RDS
- **Challenge (AI)**: Design an ML inference pipeline with Bedrock + SageMaker that scales globally
- **Judging**: Latency optimization (40%), disaster recovery (30%), cost (30%)
- **Prize**: Cross-track recognition + bonus points

#### Month 9: Cloud Architecture Jam - "Incident Response"
- **Format**: Teams of 2, 60-minute timed chaos challenge
- **Challenge**: Given a broken architecture diagram with 5 deliberate failures, diagnose and fix under pressure
- **Judging**: Failures found (40%), correct fixes (40%), speed (20%)
- **Prize**: "Incident Commander" badge + fast-track to Stage 4

#### Month 10: Cloud Architecture Jam - "Open Source Architect"
- **Format**: Individual, 75-minute challenge
- **Challenge**: Design a reusable CDK construct or CloudFormation module that solves a common problem
- **Judging**: Reusability (40%), documentation quality (30%), innovation (30%)
- **Prize**: Best module published to the community repo

#### Month 11: Cloud Architecture Jam - "Capstone Architecture Review"
- **Format**: Peer review panels (3 reviewers per capstone)
- **Challenge**: Present capstone architecture for critical review; reviewers use Well-Architected Framework checklist
- **Judging**: Architecture soundness (40%), response to critique (30%), documentation (30%)
- **Prize**: "Peer Reviewer" badge for best reviewer feedback

#### Month 12: Cloud Architecture Jam - "The Grand Design"
- **Format**: Teams of 4-5, 120-minute hackathon-style
- **Challenge**: Design the AWS Student Builder Group's own community platform (event management, leaderboard, resource hub)
- **Judging**: Innovation (30%), feasibility (30%), community impact (20%), presentation (20%)
- **Prize**: **Builder of the Year nomination** + winning design considered for actual implementation

### Retention Mechanics

#### 1. Streak System

| Streak Length | Streak Name | Bonus |
|--------------|------------|-------|
| 4 weeks | **Warming Up** | +5 bonus points |
| 8 weeks | **On Fire** | +15 bonus points + "Streak Keeper" badge |
| 12 weeks | **Unstoppable** | +30 bonus points + special mention at event |
| 24 weeks | **Half-Year Hero** | +50 bonus points + swag prize |
| 48 weeks | **Full Cycle Legend** | +100 bonus points + "Builder of the Year" nomination |

Streak counts any week where the member attends at least 2 of the 3 weekly activities (Monday, Wednesday, or Friday). Missing a week resets the streak.

**Streak Recovery**: One "streak shield" per semester - miss a week without losing your streak (must be claimed in advance via Slack message to Core Team).

#### 2. Squad System

- **Formation**: Groups of 4-5 formed in Month 1, balanced by experience level
- **Structure**: Each squad has a name, a Slack/WhatsApp channel, and a squad leader (rotates monthly)
- **Activities**:
  - Squads sit together at study circles and labs
  - Architecture Jams are squad-based competitions
  - Squad leaderboard runs parallel to individual leaderboard
  - Monthly squad challenges (e.g., "squad with most Cloud Quest completions")
- **Squad Points**: Sum of individual member points. Top squad each month gets a group reward (pizza, tech accessories, etc.)
- **Rebalancing**: Squads rebalanced at Stage 2 and Stage 3 entry to mix experience levels

#### 3. Mentorship Pairing

| Mentor (Stage 3/4) | Mentee (Stage 1/2) | Structure |
|--------------------|--------------------|-----------|
| 1 mentor | 2-3 mentees | Bi-weekly 30-min check-in |

- **Matching**: Based on shared interests (e.g., AI/ML mentor with AI-curious mentee) and schedule compatibility
- **Mentor Responsibilities**:
  - Bi-weekly check-in (15-30 min): progress review, blockers, motivation
  - Available for async questions via DM
  - Attend at least 1 mentee's Demo Day presentation
- **Mentor Rewards**:
  - 5 points per mentee per month (verified via check-in log)
  - "Mentor" badge after one full stage of mentoring
  - Priority for leadership roles and speaking opportunities
- **Mentee Responsibilities**:
  - Attend check-ins, ask questions, share progress
  - Complete weekly activities and share blockers early
